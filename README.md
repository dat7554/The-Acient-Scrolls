# ⚔️ The Ancient Scrolls

A 3D RPG prototype featuring dungeon exploration, narrative progression, and interactive gameplay systems.

> 🎮 [Watch Gameplay Demo →](https://youtu.be/1DpH4dtubGQ?si=44-__G5cR8ZRsNw5)

---

## ⚙️ Core Systems

### Character Controller
- Custom **Collide-and-Slide** movement system with slope detection, collision response, and stable traversal over uneven terrain
- **Jump buffering** and **coyote time** for responsive, forgiving controls

### Combat System
- First-person melee combat with a **stamina-based resource system**
- Full support for attacking, blocking, and resource management under pressure

### Enemy AI
- Finite State Machine (FSM) architecture driving **Patrol → Chase → Attack** behavior
- Waypoint-based patrol with closest-point initialization
- Unity **NavMesh** integration for dynamic pathfinding

### Inventory System
- Data-driven design using item metadata for flexible extensibility
- Supports **item stacking, storage**, and multi-system interactions
- Wired into combat, trading, and quest systems

---

## 🕹️ Gameplay Features

- Dungeon exploration with interactive, discoverable environments
- NPC interaction for trading and story progression
- Branching narrative system powered by **Ink**

---

## 🛠️ Built With

- Unity version 6000.0.32f1.
- NavMesh
- [Ink](https://www.inklestudios.com/ink/).
